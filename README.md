# Empresa

Portal interno del equipo.

## Uso

```bash
npm install
npm test
npm run dev
```

Abre http://localhost:5173 y entra con una persona de demostración. El selector «Entrar como» cambia el rol sin contraseña.

## Reglas de esta versión

- Contabilidad ve solo a las personas asignadas a sus proyectos.
- Publicar una nota o un programa envía una notificación al resto del equipo.
- El equipo escribe comentarios en las notas, y ese comentario también avisa.
- Las reuniones las convoca administración.
- Gerencia impulsa las sugerencias.
- Un emoji enviado a otra persona sube la confianza del equipo.

Los datos de la demostración viven en el navegador. «Restablecer demostración» vuelve al ejemplo inicial.
